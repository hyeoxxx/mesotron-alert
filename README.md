# 🪙 메소트론 알리미

메이플스토리 화면을 캡처해서 **"Collect M-Force Points!"** 이벤트 코인 획득 팝업이 뜨면 소리/알림으로 알려주는 크롬용 웹 알리미입니다.

👉 **https://hyeoxxx.github.io/mesotron-alert/**

## 사용법
1. PC 크롬(또는 엣지)에서 위 주소를 엽니다.
2. **화면 캡처 시작** → 메이플스토리 창(또는 화면 전체)을 선택합니다.
3. 팝업이 뜨면 알람음 + 윈도우 알림 + 탭 제목 깜빡임으로 알려줍니다.

- 이 탭은 다른 창에 가려져도 계속 동작합니다. 메이플을 **최소화하면** 화면이 안 잡혀요.
- **스크린샷으로 테스트**(또는 Ctrl+V 붙여넣기)로 인식이 되는지 바로 확인할 수 있습니다.
- **PIP 상태창**으로 항상 위에 떠 있는 작은 상태창을 띄울 수 있습니다.
- **탐색 영역 지정**으로 미리보기에서 드래그한 영역만 검사하면 더 빠르고 오탐이 줄어듭니다.

## 동작 방식
- `getDisplayMedia` 로 화면을 받아 Web Worker 에서 분석합니다. 화면은 브라우저 밖으로 전송되지 않습니다.
- 배너 템플릿(`assets/template.png`)과 그레이스케일 NCC(정규화 상호상관) 매칭 → 1/4 해상도 후보 탐색 후 1/2 해상도 정밀 확인 + 평균 색상 검증.
- 게임 UI 배율(60%~210%)을 자동으로 찾고, 한 번 찾으면 그 배율로 고정해서 빠르게 검사합니다.

## 로컬 실행
```bash
python -m http.server 8000
```
